# TENKI Core — Tagline System v1.0

> A two-mode brand voice: **Universal** (default) and **Trader Mode** (unlock).
> Universal voice gets you to the App Store front page.
> Trader voice keeps the professional depth for who needs it.

---

## 1. The Strategy

```
Default state             →    Universal user gets in        →   Read your inner weather.
                                                                   Find your turning point.
                                                                          ↓
[User toggles "Trader Mode" in Settings]
                                                                          ↓
Trader state              →    Professional language unlocks  →   Decision Infrastructure for Traders
                                                                   Turn volatility into turning points.
```

Why this works:
- App Store reviewers categorize TENKI under Health/Lifestyle (broader audience)
- Press/media writes about it as wellness-tech crossover, not "another finance tool"
- Traders who care discover the deeper layer through onboarding
- Both audiences feel "this app speaks to me"

## 4. The Word System

### Reserved brand words (always capitalize/use exact form)

| Word | Always written as | Never as |
|---|---|---|
| TENKI | TENKI (all caps in mark) or Tenki (in prose) | tenki / TenKi / TENKi |
| Core | Core | CORE (except in lockup wordmark · CORE) |
| Edge Score | Edge Score | edge score / EdgeScore / TEI |
| Decision Edge | Decision Edge | decision edge / DE |
| Turning Point | turning point (lowercase in prose) | TurningPoint / Turn-Point |
| Inner Weather | inner weather | InnerWeather / Inner-Weather |

### Forbidden words (never use)

- TEI / PR99 (deprecated since v3 rebrand)
- "PEAK" "OPTIMAL" as zone names — use Peak Zone / Optimal Zone
- "trader app" "fitness app" "wellness app" — TENKI is not categorized
- "stress monitor" — use "inner weather" or "biometric state"
- "AI coach" — use "decision support"

### Power words to use freely

- sense, read, feel, notice, observe (perception verbs)
- turn, shift, pivot, transition, transform (change verbs)
- baseline, rhythm, balance, breath (calm anchor nouns)
- weather, tide, wave, forecast, current (Tenki metaphor nouns)
- decisive, clear, present, ready, aware (state adjectives)

## 5. Tagline Voice Reference

### How a TENKI sentence should feel

- Quiet authority — "Return to baseline."
- Inviting — "Read your inner weather."
- Decisive — "Find your turning point."
- Poetic — "Turn the weather."

### How it should NOT feel

- Hyped — "Crush your trades!"
- Clinical — "AI-powered HRV monitoring system"
- Vague wellness — "Find your inner peace ✨"
- Tech-bro — "10X your decision velocity"
- Anxious — "Don't miss your moment!"

---

## 6. Tagline Test

Before publishing any new tagline copy, ask:

1. Could a 60-year-old grandma understand it? (Universal tier only)
2. Could a Citadel trader feel it speaks to them? (Trader tier only)
3. Does it use the Tenki "weather" metaphor consistently?
4. Is it 8 words or fewer? (Mobile UX rule)
5. Does it work in both English and Chinese without distortion?

If all 5 are yes for the appropriate tier — ship it.

## 7. Localization Notes

### Chinese (繁體中文)

The Mandarin translation is direct, not paraphrased. Specifically:

- "inner weather" = 內在氣象 (literal, evocative)
- "turning point" = 轉機 (single character beauty: 轉 = turn, 機 = moment/opportunity — same kanji as Tenki's 気)
- "baseline" = 本心 (literally "original heart/mind" — more poetic than the medical 基線)
- "Sense the shift" = 感知變化 (perception + change, no flourish)

### Japanese (future)

If TENKI launches in Japan:
- Tenki kanji is 天気 — keep this in marketing, it ties product name to weather metaphor literally
- "inner weather" = 内なる天気 (formal, reverent) or あなたの天気 (intimate — "your weather")
- "turning point" = 転機 (also kanji 転 + 機, perfect parallel)

The product name TENKI is the same word in Japanese for "weather" — this is no accident. The Japanese release will be a homecoming for the brand.
