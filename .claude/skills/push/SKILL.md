# Push Workflow

1. Show staged and unstaged changes with `git status` and `git diff --stat`
2. Stage all relevant changes (avoid .env or credential files)
3. Create a descriptive commit message following the project convention: `<type>(<scope>): <description>`
4. Describe the plan and wait for user confirmation before committing
5. Push to the current branch on origin with `git push -u origin <branch>`
