概念

風掃過的浪 — TENKI（天気）讀的是你的內在天氣。實心的浪頭是當下的狀態，向後流動的線是訊號的軌跡與節律。白色 on 深海軍藍是 canonical 配色。

三段式 lockup：mark → TENKI（SF Pro Display・weight 200・字距 0.32em・白）→ CORE（weight 600・字距 0.4em・#00B4D8 + cyan glow）。

使用規則

✓白色 on 深海軍藍（#0A1628→#050A14）為 canonical；cyan / gold 僅作語境點綴。
✓動態：入場 900ms cubic-bezier(0.2,0.7,0.3,1)、待機 6s 呼吸 scale 1.015 — 與 v6 splash 一致。
✓Clear space = mark 高度的 25%；wordmark 與 CORE 的字距規格不可改。
✗不重繪、不描邊化、不改浪的形狀、不加 3D / 漸層填色 / 外發光（CORE 字的 glow 除外）。
✗不與任何舊資產（Expo 佔位符、探索版圓形 mark）混用。
