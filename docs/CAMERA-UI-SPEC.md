# CAMERA-UI-SPEC.md — 指尖 PPG 校準相機介面設計規格

> Phase 2-3 實作參考。Phase 0 不需要碰此文件。
> 最後更新：2026-03-02

## 實作路線圖

### MVP（Phase 2，需要 Mac）
選項 1（靜態圖形疊加）+ 選項 6（漸進式引導層）
- 開發時間：1 週
- 成功率預期：75-80%
- 純前端實作，不需額外依賴

### v2.0 進階版（上架後優化）
選項 3（即時輪廓追蹤）+ 選項 5（熱感應視覺化）
- 開發時間：3-4 週
- 成功率預期：90-95%
- 差異化賣點：首款即時視覺反饋的 PPG 校準系統
- 需要電腦視覺整合（MediaPipe / OpenCV）

## 7 種設計模式（從簡單到複雜）

### 選項 1：靜態圖形疊加（MVP 採用）
- 半透明白色輪廓標示鏡頭區域
- 脈動動畫（1 秒週期，透明度 30%-60%）
- 文字標籤「Place finger here」
- 開發 1-2 天，< 10KB

### 選項 2：AR 3D 手指模型
- 半透明食指 3D 模型浮現在鏡頭上方
- 放置動畫（2 秒循環下降）
- 需要 AR 框架（+15-20MB），開發 2-3 週
- 用戶理解度 > 90%

### 選項 3：即時輪廓追蹤（v2.0 採用）
- 手指輪廓偵測 + 覆蓋率計算
- 三色漸變：🔴 未覆蓋 → 🟡 部分 → 🟢 完全
- 箭頭指示移動方向
- 提升成功率 40%，嘗試次數從 3.2 降至 1.4
- CPU 持續 30-40%

### 選項 4：網格對齊系統
- 3×3 九宮格 + 中心十字準星 + 水平儀
- 專業醫療感，增加信任度
- 視覺複雜度高，老年用戶可能困惑

### 選項 5：熱感應視覺化（v2.0 採用）
- 熱力圖疊加 + 血管脈動動畫 + 品質環形進度條
- 高科技感，即時反饋
- 需要 ≥ 30 FPS，消耗電池

### 選項 6：漸進式引導層（MVP 採用）
- 階段 1（0-3s）：定位 — 手機背面插圖 + 鏡頭高亮
- 階段 2（3-8s）：接近 — 相機視圖 + 虛線框
- 階段 3（8s+）：微調 — 實時品質分數 + 方向箭頭
- 降低認知負荷，適合首次使用者

### 選項 7：混合實境標記
- QR 風格鏡頭標記（手機殼貼紙）
- 內建 200+ 機型鏡頭位置數據庫
- 零學習成本但需要實體貼紙

## 競品參考
- Welltory：使用選項 3（輪廓追蹤）
- Shen AI：使用選項 2（AR 模型）
- 專業醫療設備：選項 4 + 實體指尖固定器

## 與 TENKI 現有系統的整合點
- SQI (sqi.ts)：品質進度條的數據來源
- rPPG ROI 優先級（ANTIGRAVITY.md Section 6.1）：眉心 > 前額 > 臉頰
- 指尖 PPG 是 rPPG 之外的第二校準管道
- 熱感應視覺化可複用 Stardust Soul 的粒子系統色彩語言
