# docs/archive — 已歸檔文件索引

這裡放**已被取代但保留決策軌跡**的文件。

歸檔不等於刪除，也不等於否決。放進來的原因通常是「它與現行 canonical 來源矛盾」，
而不是「它錯了」——當初它是對的，只是世界往前走了。想知道「當初為什麼是那樣決定的」，
答案在這裡。

## 規則

1. **原文照搬不改寫**（`.cursor/harness/05_maintenance.md` §4）。
   歸檔文件內文一個字都不動 —— 包含其中所有過時的數字。
   修掉那些數字就失去歸檔的意義。
2. 只在檔頭加一段 blockquote banner，說明歸檔日期、原路徑、被什麼取代。
3. 檔名帶版本後綴（`-v2`、`-v1`、`-2026H1`），標示歸檔的是哪一版。
4. **不要引用這裡的文件當作依據。** 有疑問一律回到現行來源。
