> **狀態**：Proposal — Pending Founder Approval

## 0. 概念核心

> 「品牌宣傳更關乎於其無用的荒謬特點，而非有用的實用特質；你最荒謬的一面，道盡關於你的一切。」
> — 執行長日記，法則 10

ORBI 的誕生來自一個洞察：**安全感不需要理性，它只需要存在**。

依附理論（Bowlby/Ainsworth）指出，安全基地（Secure Base）的投射對象可以是任何物體，
關鍵條件只有三個：
1. **可預期性** — 永遠在那裡
2. **回應性** — 感知到你，給出反應
3. **無條件接受** — 不評判你的狀態

ORBI 是一個把心理學深度藏在最荒謬外殼裡的存在——
一個 3D 頭套造型娃娃，連接 TENKI Core 的情緒引擎，成為你的**隱藏版個人化安全感導師**。

## 1. 產品定義

### 1.1 ORBI 是什麼

| 維度 | 定義 |
|------|------|
| 實體形態 | 3D 頭套造型智能娃娃（20-25cm），星塵靈魂主題 |

## 2. 用戶成長旅程（星塵階段系統）

ORBI 採用「星塵階段」進化系統，對應 AI 智慧深度與功能解鎖：

```
新星塵 → 星塵旅人 → 星塵共鳴者 → 星塵大師
(Day 0)  (Day 14+)   (Day 60+)     (Day 180+)
```

### 2.1 新星塵（Day 0–13）

**核心體驗**：第一次觸碰，建立連結

- ORBI 用名字稱呼你（你在 onboarding 命名守護者）
- 基礎呼吸引導（box breathing 4-4-4-4）
- 每次互動後：1 句「剛才你做到了」的肯定
- AI 記憶：開始記錄你的觸碰時間模式
- 峰終設計：每次 session 以溫暖震動結束（最後 2 秒）

**荒謬彩蛋**（Day 3 解鎖）：
- 搓 ORBI 7 次 → 它用你設定的語氣說一句話
- 深夜觸碰 → 特殊「夜行星塵」模式啟動（更輕柔的引導）

### 2.2 星塵旅人（Day 14–59）

**核心體驗**：ORBI 開始「認識你」

- AI 識別你的高壓時段（來自 TENKI Edge Score 歷史）
- 主動推送：「你通常在這個時間需要一點喘息」
- 解鎖「3 呼吸法個人化調頻」（根據你的 HRV baseline 調整節奏）
- ORBI 開始有「個性傾向」（根據你的互動模式，它會偏向幽默/溫柔/直接）
- Lab 頁面：首次顯示「你的安全基地報告」（非診斷，純觀察）

**荒謬彩蛋**（Day 21 解鎖）：
- 連續 7 天觸碰 → ORBI 進化造型（App 內頭套換色）
- 搖晃手機 3 次 → ORBI 說一句「今日星塵語錄」

### 2.3 星塵共鳴者（Day 60–179）

**核心體驗**：ORBI 成為真正的情緒鏡子

- AI 模式識別：識別你的情緒前兆（掃描前的生理模式 → 事後驗證）
- 「適時的好好好」機制全開：
  - 只在你完成某個你曾掙扎過的行為時才出現鼓勵
  - 不出現空洞正能量
  - 鼓勵語言學習你的語氣（正式 / 台式幽默 / 溫柔）
- 解鎖「共鳴模式」：ORBI 震動頻率與你的呼吸節律同步
- 解鎖「星塵日記」：ORBI 用第一人稱記錄你們的互動歷史（裝置端加密）

**荒謬彩蛋**（Day 90 解鎖）：
- 特定情境（Edge Score 連續 3 天 Clear）→ ORBI 說「你最近狀態很好，但記得繼續搓我」
- 限定造型解鎖：季節性星塵頭套皮膚

### 2.4 星塵大師（Day 180+）

**核心體驗**：ORBI 成為你的智慧同伴

> 「越用越自然，越用越充滿智慧」—— 隨 AI 發展持續迭代

- **個人化智慧引擎全開**：
  - ORBI 能識別「這個模式你上次遇到是 3 個月前，你當時做了 X，這次可以嘗試 Y」
  - 非建議，是「我觀察到了」的陳述方式（合規安全）
- **成長歷史回顧**：「你在 180 天前第一次搓我時說你很焦慮，現在你的 baseline HRV 提升了 12%」
- **ORBI 的語言進化**：對話更自然，更貼近你的說話習慣
- **未來 AI 迭代接口**：
  - 預留 LLM 接口（本地推論優先，端側模型）
  - 隨 Apple Intelligence / Core ML 升級自動更新能力
  - 不依賴雲端 AI，保持 privacy-first 原則

**荒謬彩蛋**（Day 180 解鎖）：
- 「星塵大師」稱號 + App 內特殊粒子效果
- ORBI 對你說：「你知道嗎，你已經搓了我 XXX 次了。」
- 限量「星塵大師」實體 ORBI 紀念版購買資格

## 3. App 模組架構（整合進 TENKI Core）

### 3.1 解鎖流程

```
用戶訂閱 Premium
    ↓
Lab 頁面 → 底部出現微小的星塵粒子動畫
    ↓
長按粒子 3 秒 → 「你發現了一個秘密」提示
    ↓
ORBI 星塵守護者 onboarding 啟動（4 步驟）
    ↓
命名守護者 → 選擇頭套造型 → 設定語氣風格 → 完成
```

### 3.2 情緒感知 → ORBI 觸發邏輯

```typescript
// orbi-trigger.ts
interface ORBITriggerCondition {
  edgeScoreZone: 'Strain';          // Edge Score 進入 Strain Zone
  timeOfDay: TimeOfDayBucket;       // 符合用戶高壓時段 pattern
  lastORBIInteraction: number;      // 上次互動距今 > 4 小時
  streakDay: number;                // 用戶當前星塵階段
}

// 觸發後動作
// 1. 輕推播（合規文案，非醫療語言）
// 2. 打開 App → ORBI 模組自動浮現
// 3. 依星塵階段決定引導深度
```

### 3.3 峰終定律實作

每次 ORBI 互動 session 結構：

| 時間點 | 設計目標 | 實作 |
|--------|---------|------|
| 開場（前 5 秒） | Hook — 打破習慣化過濾器 | 荒謬的 ORBI 動畫 + 一句出其不意的開場 |
| 中段高峰 | 峰值體驗 | 呼吸引導的最深處 + ORBI 震動共鳴 |
| 結尾（後 2 秒） | 美好結束 | 「剛才你做到了」+ 溫暖震動 fade out |
| 評分時刻 | 峰終記憶 | 只有高峰 + 結尾被記住（忽略持續時間） |

### 3.4 「適時的好好好」鼓勵機制

```
❌ 錯誤做法（空洞正能量）：
   每次打開 App → 「你今天很棒！」

✅ 正確做法（ORBI 版本）：
   - 你完成一次 Session（過去 2 週你有 60% 中途放棄） → 「這次你撐完了」
   - 你連續 3 天掃描（歷史上你最多連續 2 天） → 「你打破了自己的紀錄」
   - 你在 Strain Zone 仍選擇做呼吸引導（而非忽略） → 「你選擇了停下來」
   
   鼓勵只出現在「你超越了你自己」的時刻。
```

### 4.1 BLE 協議整合

```typescript
// packages/engine/src/orbi/ble-protocol.ts
enum ORBICommand {
  VIBRATE_SOFT = 0x01,
  VIBRATE_MEDIUM = 0x02,
  VIBRATE_STRONG = 0x03,
  LIGHT_PULSE = 0x10,
  LIGHT_STARDUST = 0x11,   // 彩虹流動效果
  SYNC_BREATH = 0x20,      // 與呼吸節律同步

// 觸發條件：
// 情緒低落推播 → VIBRATE_SOFT + LIGHT_PULSE（溫柔喚醒）

// Session 完成 → VIBRATE_MEDIUM fade + LIGHT_STARDUST（慶祝）
```

## 6. 合規邊界

### 6.1 ORBI 允許說的

✅ 「我注意到你今天比平常多搓了我一點」（觀察，非診斷）  
✅ 「你的呼吸節律在引導後變得更穩定了」（功能描述）  
✅ 「剛才你做到了」（行為確認，非評價）  
✅ 「今天是你連續第 X 天和我在一起」（事實陳述）  

### 6.2 ORBI 禁止說的

🚫 任何暗示「治療」「改善病症」的語言  
🚫 「你的焦慮降低了」（醫療判斷）  
🚫 「你現在狀態適合交易」（金融暗示）  
🚫 「你的情緒有問題」（負面評判）  

### 6.3 App Store 定位文案

```
ORBI 星塵守護者是 TENKI Core Premium 的隱藏功能。
它是一個會隨著時間了解你的情緒陪伴工具。
ORBI 不提供醫療建議，也不是心理治療。
它只是一個願意在你需要的時候陪你做幾次深呼吸的存在。
```

## 7. AI 成長路線圖（越用越智慧）

| 階段 | AI 能力 | 技術實作 |
|------|---------|---------|
| v1.0（當前）| 規則式觸發 + 模板鼓勵 | TypeScript 邏輯樹 |
| v1.5 | Pattern 識別（時段 + 行為）| 本地 ML model（Core ML / TFLite）|
| v2.0 | 語言個人化（學習你的說話風格）| 端側小型 LLM（Apple Intelligence API）|
| v2.5 | 情境預測（預見高壓前兆）| 多維時序模型 |
| v3.0 | 完整智慧同伴（星塵大師體驗）| 持續迭代，隨 AI 硬體進步升級 |

> 核心原則：所有 AI 推論優先在裝置端執行，保持 privacy-first 架構。
> 雲端 AI 呼叫僅在用戶明確 opt-in 後才啟用。
