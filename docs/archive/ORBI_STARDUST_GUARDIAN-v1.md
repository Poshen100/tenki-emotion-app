## 2. 心理學基礎

### 2.1 依附理論（Bowlby / Ainsworth）

安全基地的三個核心條件：

1. **永遠在那裡**（可預期性）→ ORBI 實體永遠不會關機、不會生氣
2. **回應你**（responsiveness）→ 觸碰有震動回饋、App 有語音/文字呼應
3. **不評判你**（unconditional positive regard）→ ORBI 的 AI 從不批評，只陪伴

你兒子搓熊貓娃娃這件事是最好的 proof of concept：**安全感的投射對象不需要理性，只需要存在。**

### 2.2 峰終定律（Kahneman）

每次 ORBI 互動必須設計「高峰 + 美好結尾」：

- **高峰**：呼吸引導的最放鬆瞬間（ORBI 發出輕微暖光）
- **結尾**：一句剛好說中你的鼓勵（AI 個人化，不是罐頭文）

→ 這讓使用記憶停在好的感覺，驅動下次再開。

### 2.3 漸進揭示（Progressive Disclosure）

ORBI 的 AI 智慧不是一次給完，而是隨著使用次數**緩慢解鎖**：

```
Day 1-7     → 星塵新生    基本呼吸陪伴
Day 8-30    → 星塵覺醒    開始記得你的習慣
Day 31-90   → 星塵成長    個人化語氣成形
Day 91-180  → 星塵守護    主動在對的時機出現
Day 181+    → 星塵大師    幾乎像一個了解你的老朋友
```

越用越自然，越用越充滿智慧——**AI 的成長就是留存機制本身。**

### 4.3 星塵大師階段的 AI 行為差異

| 行為 | 新生期 | 大師期 |
|------|-------|-------|
| 呼吸引導 | 標準 4-7-8 說明 | 知道你偏好哪種節奏，直接進入 |
| 鼓勵語氣 | 通用正向語句 | 引用你過去的突破紀錄 |
| 出現時機 | 只在 Strain Zone 觸發 | 預測性——在你還沒掉進 Strain 前主動出現 |
| 語言風格 | 中性友善 | 貼近你設定的人格（嚴肅師父 / 溫柔陪伴 / 幽默同伴）|
| 彩蛋 | 無 | 特定日子（你的生日、連續 100 天）有驚喜 |

## 5. 實體 ORBI 規格（Phase 2）

### 5.1 硬體設計原則

- **外形**：星塵靈魂主題宇宙生物，20-25cm，刻意設計得「可愛但詭異」
- **材質**：介於公仔與玩具之間，表面輕微霧感，手感溫潤
- **顏色**：星塵銀 / 星雲紫 / 隕石灰（每季新增限定色）

### 5.2 感測與輸出

| 硬體元件 | 功能 |
|---------|------|
| 觸控感應層 | 偵測輕搓/握持動作 |
| 震動馬達（ERM） | 呼吸節奏同步震動 |
| RGB LED 環境光 | Zone 狀態光暈（藍=清晰、橙=中性、紅=緊繃）|
| 陀螺儀 | 偵測被拿起/放下動作 |
| BLE 5.0 | 低功耗連線 App |
| USB-C 充電 | 7天續航（輕度使用）|

### 5.3 荒謬彩蛋清單（對標特斯拉復活節彩蛋）

| 觸發方式 | 彩蛋 |
|---------|------|
| 連搓 10 下 | ORBI 震動出《嗶嗶嗶》的節奏，App 顯示「你真的很無聊，但這正說明你需要休息」|
| 凌晨 3 點互動 | 特殊深夜模式，語氣變成「...你怎麼還沒睡」|
| 使用滿 365 天 | ORBI 發出一次長震動，App 彈出「一年了。你一直在這裡，我也是。」|
| 連續 7 天不用 | 推播：「你還好嗎？我有點想你。」（僅此一次）|

```
Free        NT$0     每日 3 次掃描，基本功能
Pro         NT$149/月  全功能 + ORBI App 模式解鎖

```

**實體購買**（一次性）：

```
ORBI 標準版    NT$1,480  星塵銀 / 隕石灰
ORBI 限定版    NT$1,980  每季一款，限量 500 個
ORBI 創始版    NT$2,480  含創始人編號刻字，永不再版
```

### 6.2 App Store 合規策略

- **定位**：「情緒陪伴工具」，非「心理治療」
- **實體不在 App 內販售**：引導至官網，規避 Apple 30% 抽成
- **AI 功能描述**：「根據你的使用習慣個人化引導」而非「AI 分析情緒」
- **免責聲明**（沿用 ANTIGRAVITY Section 2.3 合規架構）：

```
ORBI 星塵守護者是情緒陪伴工具，不提供醫療診斷或心理治療。
如有心理健康需求，請尋求專業協助。
所有互動記錄儲存於裝置端，從不上傳。
```
